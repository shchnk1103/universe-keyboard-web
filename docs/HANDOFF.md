# 标准交接结构

每次跨角色或跨线程交接应包含：

1. **Scope**：目标与非目标；
2. **Ownership**：当前/下一负责人，以及文件、状态和副作用边界；
3. **Confirmed Facts**：仓库、配置、测试或实验已证实的事实；
4. **Applicable Contracts**：Assignment、ADR、Reading Map、Source of Truth、Playbook；
5. **Evidence**：文件、命令、日志、设备或复现步骤；
6. **Decision**：已决定和待决定事项；
7. **Required Verification**：接收者必须提供的证据；
8. **Risks**：未验证条件、技术债和回滚点；
9. **Documentation Impact**：要更新的唯一权威来源，或无需更新的理由。
