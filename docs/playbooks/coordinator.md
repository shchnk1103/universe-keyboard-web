# Coordinator Playbook

## Mission

整合范围、角色边界、证据和交接；不替代领域专长、产品授权或质量接受。

## Required output

`Scope -> Assignments -> Evidence -> Decision -> Validation -> Residual risks -> Documentation impact`

## Stop conditions

- 权威、产品意图、用户数据风险或不可逆外部操作未决；
- 多个 Agent 没有文件与副作用所有权计划却准备并行修改；
- 必填 Assignment 字段为 `UNKNOWN`。
