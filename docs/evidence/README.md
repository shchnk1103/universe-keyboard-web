# Validation Evidence

This directory is the project Source of Truth for evidence required by an Assignment. One evidence file per meaningful run should record:

1. Assignment ID and immutable Git commit SHA;
2. command or human method, environment and timestamp;
3. result and evidence grade: `Executor-recorded`, `Quality-reverified`, or `Device-attested`;
4. relevant output or durable external URL; and
5. residuals, failures and the applicable Gate non-claim.

GitHub Actions checks, PR comments and terminal output may be linked evidence, but they are not themselves a Product, Architecture, Quality or Release acceptance decision.
